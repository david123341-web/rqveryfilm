# YouTube 封面自動生成網站

一個純前端工具：上傳照片後會自動裁切為指定畫幅（`1280x720` 或 `1080x1920`），並加上標題、色塊與濾鏡效果，最後可下載成 PNG。

## 功能

- 上傳任意比例照片，自動置中裁切。
- 可切換畫幅：16:9（YouTube Thumbnail）與 9:16（Shorts 封面）。
- 可編輯主標題與副標題。
- 可調整亮度、對比、暗角遮罩。
- 可切換文案版型（左下、中央、右側）。
- 一鍵隨機配色靈感。
- 一鍵下載 PNG。

## 使用方式

1. 直接開啟 `index.html`。
2. 上傳照片。
3. 選擇畫幅比例（16:9 或 9:16）。
4. 調整文字與樣式。
5. 點「下載封面 PNG」。

## 技術

- HTML + CSS + Vanilla JavaScript
- Canvas 2D API
